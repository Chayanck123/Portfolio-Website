### 🤖 Chayan AI Copilot
An intelligent conversational agent embedded directly into the portfolio:
* **Multi-Turn Dialogue Memory**: Understands contextual follow-ups (e.g., *"What did he build there?"*).
* **Candidate Intelligence (0ms latency)**: Instant direct answers for notice period (**30 days**), age (**24 years old**), Python experience (**3+ years**), research publications, patents, and target roles.

* **Global Keyboard Shortcuts**: Press **`⌘K`** or **`Ctrl+K`** from anywhere on the portfolio to toggle the copilot, or **`Esc`** to close.

* **Interactive Site Navigation**: Direct action cards that smoothly scroll the page to relevant sections (`#work`, `#career`, `#about`, `#contact`).
* **One-Click Code Copy**: Syntax-highlighted code blocks with animated copy-to-clipboard feedback.

## 🚀 Getting Started

### Prerequisites
* Node.js (v18 or higher recommended)
* npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Chayanck123/Portfolio-Website.git

# Navigate into the project directory
cd Portfolio-Website

# Install dependencies
npm install

# Start the local development server
npm run dev
```

### Production Build
```bash
# Compile TypeScript and bundle with Vite
npm run build

# Preview production build
npm run preview
```
